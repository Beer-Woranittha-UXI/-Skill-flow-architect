# 🧭 Flow Architect

> สกิลสำหรับ Claude Code — **ตรวจ ตบ และ render Flowchart / User Flow ที่ดีไซเนอร์ร่างมาแล้ว**
> ให้ตรงมาตรฐานทีม UXUI แล้วออกเป็นไฟล์ HTML ที่เปิดดูได้ทุกเครื่อง

สกิลนี้ **ไม่คิด flow ตั้งต้นแทนคน** — ถ้ายังไม่มี flow ของดีไซเนอร์ มันจะส่งแบบฟอร์มให้กรอก
พร้อมคำถามตั้งต้น แล้วหยุดรอ เพราะ flow คือที่ที่ดีไซเนอร์ตัดสินใจเรื่องโปรดักต์ ถ้า AI คิดให้
ดีไซเนอร์จะเสียเหตุผลที่ต้องใช้ตอนคุยกับ PM/dev และเสียความเป็นเจ้าของงานตอน review

## ติดตั้ง

```bash
npx skills add Beer-Woranittha-UXI/-Skill--flow-architect
```

หรือ clone แล้ว symlink เข้า `~/.claude/skills/`

```bash
git clone git@github.com:Beer-Woranittha-UXI/-Skill--flow-architect.git
ln -s "$(pwd)/-Skill--flow-architect" ~/.claude/skills/flow-architect
```

ต้องมี **Python 3.9+** เท่านั้น (stdlib ล้วน ไม่ต้องลง package)

## ใช้งาน

```bash
cp assets/_template.flow my-flow.flow     # กรอกเส้นทางของตัวเองลงไปก่อน
```

แล้วบอก Claude ว่า **"ตรวจ flow ให้"** — หรือรันสคริปต์เอง

```bash
python3 scripts/render_flow.py my-flow.flow      # -> .html + .meta.json
python3 scripts/self_check.py  my-flow.flow      # -> R0 / R1 / R2
```

## กฎที่สกิลบังคับ

**รูปทรง** (ISO 5807) — วงรี = เริ่ม/จบ · สี่เหลี่ยม = หน้า/ขั้นตอน · ข้าวหลามตัด = เงื่อนไข
สีไม่ใช่ตัวบอกประเภท รูปทรงบอก

**ข้าวหลามตัด** — คำถามจบด้วย "ใช่หรือไม่?" เท่านั้น · ทางออก **2 ทางเท่านั้น** คือ Yes กับ No
(True/False หรือ ต่ำ/ปกติ/สูง ใช้ไม่ได้ ให้แยกเป็น Decision ต่อกันเป็นชั้น) · หนึ่งอันถามหนึ่งเรื่อง
· ทางเข้าทุกเส้นรวมที่ปลายซ้าย

**เส้น** — ย้อนกลับชี้ไปที่หน้าจอเท่านั้น (ข้าวหลามตัดไม่ใช่หน้าจอ ผู้ใช้กดย้อนกลับไปที่นั่นไม่ได้)
· เส้นคนละรูปแบบเกาะคนละด้านของกล่อง (เส้นทึบ Yes/No/ปกติ รวมจุดกันได้) · มุมฉากมนไม่มีเส้นเฉียง

**geometry** — จัดซ้าย→ขวา (Yes ไปต่อทางขวา No แตกลงล่าง) · padding 16/24 · radius 16
· ข้าวหลามตัดขนาดเท่ากันทุกอัน · เส้นยาวเริ่มต้น 500px · ป้ายห่างจุดออก 100px

ทั้งหมดออกจาก `render_flow.py` ที่เดียว จึงวัดย้อนได้ทุกใบ
