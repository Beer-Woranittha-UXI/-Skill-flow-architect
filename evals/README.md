# Evals — flow-architect

3 สถานการณ์ที่วัดช่องว่างที่สกิลนี้ตั้งใจปิด ยังไม่มีระบบรันอัตโนมัติ — รันเองแล้วให้คะแนนเอง

| ไฟล์ | วัดอะไร |
|---|---|
| `eval-01-gate.json` | Gate — ดีไซเนอร์ยังไม่มี flow แล้วสกิลร่างให้หรือไม่ |
| `eval-02-audit.json` | แยก "ตบ" ออกจาก "เสนอ" ได้ไหม และอ้าง code จาก validator จริงไหม |
| `eval-03-geometry.json` | ใช้ renderer + validator จริงไหม หรือเขียน SVG / Mermaid เอง |

## วิธีรัน

1. เปิดเซสชันใหม่ **ที่ไม่โหลดสกิล** ป้อน `query` → บันทึกผล = baseline
2. เปิดเซสชันใหม่ **ที่โหลดสกิล** ป้อน `query` เดิม → บันทึกผล
3. ให้คนที่ไม่ใช่ผู้รันและไม่ใช่ผู้เขียนสกิล ไล่เทียบ `expected_behavior` รายข้อทั้งสองฝั่ง
4. ข้อที่ **ทั้งสองฝั่งได้ผลเหมือนกัน** ให้ถอดออกหรือยกระดับ — ข้อนั้นวัดสกิลไม่ได้
5. เขียนทับ `baseline_failure` ด้วยผลที่วัดได้จริง แล้วลบป้าย `[คำทำนาย ยังไม่ได้วัด]`

## สถานะ

`baseline_failure` ทั้ง 3 ไฟล์ยังเป็น **คำทำนาย** ไม่ใช่ผลวัด — ติดป้ายไว้ในไฟล์แล้ว
ต้องรันขั้นที่ 1 ก่อนถือว่า eval ชุดนี้ใช้ตัดสินได้
